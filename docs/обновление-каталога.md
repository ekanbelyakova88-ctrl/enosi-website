# Как обновить каталог ENOSI

Сейчас управление товарами устроено через файлы проекта. Удобной панели для самостоятельного редактирования пока нет. Приведённые действия требуют доступа к репозиторию GitHub и некоторой помощи разработчика; фотографии на действующем сайте меняются только после отдельной публикации.

1. Подготовьте фотографии изделия и запишите название, состав, цену, тип (браслет, колье или комплект) и другие подтверждённые сведения. Для комплекта перечислите изделия внутри. Проверяйте, чтобы фото показывали именно этот товар.
2. В проекте данные находятся в `src/data/products.js`, сведения о камнях — в `src/data/stones.js`, фотографии — в `src/assets/gallery` и `src/assets/set-styled`. Цены новых позиций задаются числом в поле `price`. Для прежних браслетов действует общая цена 1 990 ₽; чтобы назначить отдельную цену, добавьте конкретному товару поле `price`.
3. Для нового изделия задайте неповторяющийся `id`, название `name`, `type`, `price`, `materials`, текст `description` и `detail`, изображения `cover` и `galleries`. Добавьте подтверждённые камни в `productStones`. Новый товар без фото показывает честную надпись «Фото украшения готовится».
4. На компьютере разработчика выполните `npm test` и `npm run build`. Посмотрите каталог и карточку на телефоне и компьютере, проверьте цену, состав, последовательность изображений и ссылку Telegram.
5. Сначала отправьте изменения на просмотр владелице. Действующий сайт обновляется отдельным запуском GitHub Actions: `Publish ENOSI demo` → `Run workflow` → ветка `main`. Запускать публикацию только после согласования владелицей.

Стоимость доставки, способы оплаты и сроки изготовления редактируются в списке `questions` в `src/main.jsx`. Контакт Telegram находится в `src/data/products.js`. Не вписывайте неподтверждённый состав или цены.
