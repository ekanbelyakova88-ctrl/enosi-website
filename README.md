# enosi-website
Официальный сайт бренда авторских украшений ENOSI из натуральных камней

Первая демонстрационная главная страница. React + Vite, адаптивная вёрстка, локальные шрифты и изображения. Без оплаты, корзины, регистрации и отправки личных данных.

## Посмотреть дизайн без установки программ

В подготовленной среде откройте папку `preview`. Скачайте `ENOSI.html` и откройте его обычным двойным щелчком в браузере. Это вся страница в одном файле: фотографии, шрифты и интерактивные элементы работают без интернета. Файл не публикует сайт.

Рядом находятся снимки компьютерной и мобильной версии. Они показывают дизайн, а HTML позволяет нажимать кнопки.

## Запуск для разработки

Нужен Node.js 20.19+ или 22.12+ (среда проверена с Node.js 24).

Из папки `/workspace/enosi-website`:

```sh
npm ci
npm run dev -- --port 5173 --strictPort
```

Сервер предназначен для разработки. В облачной среде доступ с личного компьютера зависит от возможностей перенаправления портов в интерфейсе. Если их нет, используйте самостоятельный файл `preview/ENOSI.html`.

Другие команды:

```sh
npm run build   # собрать готовую страницу в dist/index.html
npm run demo    # собрать и обновить самостоятельный preview/ENOSI.html
npm test       # проверки страницы в Chromium: компьютер и телефон
```

Для тестов автоматически используется Chromium из `/usr/bin/chromium`, если он установлен. Иначе установите браузер Playwright командой `npx playwright install chromium`. Можно указать путь в переменной `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

## Как заменить фотографии и тексты

Все фотографии сгенерированы для демонстрации. Названия и состав моделей — предложения для будущей коллекции, а не сведения о реальных изделиях или наличии. На странице это обозначено явно. Изображения из переписки послужили визуальными референсами.

- `src/assets/hero.webp` — фото первого экрана и блока о бренде.
- `src/assets/collection.webp` — три демонстрационные фотографии рядом, равными частями. Их позиции заданы классами `.product-0`, `.product-1`, `.product-2` в `src/styles.css`. При переходе к реальным фото лучше заменить общую композицию отдельными файлами каждого изделия.
- Массив `products` в `src/main.jsx` — названия, состав и описания.
- В `src/main.jsx` также находятся тексты, меню и окно контактов.
- Палитра, размеры и адаптация — `src/styles.css`.

После изменений выполните `npm run demo`, чтобы обновить файл для просмотра.

## Идея дизайна

Светлый кремовый фон, шалфейные акценты, пудровые фактуры, элегантная типографика и знак из двух плавных форм. Особенность страницы — выбор «своего сочетания» по оттенку. Он отражает свободу выбора и соединение разных элементов в философии ENOSI.

Сравнение с актуальными сайтами конкурентов не выполнено: запросы к Missoma и Avgvst заблокированы сетевыми правилами среды. Дизайн основан на философии и референсах, предоставленных автором бренда.

Публикация в интернете не выполнялась. Для запуска настоящих заказов отдельно понадобятся реальные фотографии, утверждённый ассортимент, контакты и условия покупки.
