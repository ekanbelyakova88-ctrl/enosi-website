# Конструктор ENOSI: состояние модернизации

Единое состояние и миграция — `builder-model.js`. Материалы, цены и остатки — `data/materials.js`. Неизвестные цены остаются null. Расчёт состава, цены и условной вместимости — `bracelet-calculations.js`. Производственные припуски и стоимость работы заполняются только по данным автора.

Расчёт круглых бусин использует радиусы центров относительно внутренней окружности и угол соприкосновения соседних сфер по теореме косинусов. Он активен только при подтверждённом припуске. Для неправильных форм без длины вдоль нити требуется проверка мастера. Расчёт не гарантирует посадку. Пока припуски не заданы, интерфейс сообщает об этом.

`Bracelet3D.jsx` загружается по требованию. Three.js строит объёмную геометрию каждой бусины. OrbitControls управляет камерой. Рендеринг выполняется при изменениях камеры и размера, pixel ratio ограничен 1.5. Геометрия и материалы освобождаются при закрытии. Цвет берётся из каталога; матовая поверхность имеет большую шероховатость. Неровные формы процедурные, не сканы изделий. Фотографии всей бусины не используются как ложные бесшовные текстуры.

`PersonalStart.jsx` сохраняет дату, несколько тем и свободное описание. Знак определяется по условным календарным границам, пограничные даты помечаются. Подбор камней по зодиаку и минералогический справочник с проверенными источниками пока отсутствуют. Все пять референсов отклонил сетевой прокси (CONNECT 403), их исследование не выполнено.

Передача заказа работает через Telegram/MAX с описанием и скачиваемым изображением. Это согласование с автором, не серверная регистрация заказа. Проверяется доступность материалов по локальному каталогу; реальный остаток и цену подтверждает автор.

Игровой поднос реализован на Canvas: гравитация, отскоки, попарные столкновения, сборка в круг, две темы и звук Web Audio по желанию. Он использует те же ID элементов.

Не завершены: подтверждённые связи камней со знаками; рекомендательная композиция по нескольким камням; высококачественная модель запястья; персональная точная примерка. Текущее фото-наложение остаётся приблизительным эскизом и так подписано.

Для продолжения нужны реальные цены компонентов, стоимость работы, припуски, осевые длины неправильных форм, подтверждённая фурнитура/конструкции, остатки и разрешённый доступ к источникам. Не подставлять вымышленные значения ради активации расчётов.
