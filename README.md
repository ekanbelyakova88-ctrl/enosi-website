# ENOSI — авторские украшения из натуральных камней

Сайт: **https://ekanbelyakova88-ctrl.github.io/enosi-website/**

Обновлённая главная страница с логотипом владельца, четырьмя реальными моделями браслетов, галереями оригинальных фотографий и прямой связью с автором: **https://t.me/BeliakovaKaterina**.

## Идея страницы

«Ваше сочетание»: ярче выраженные шалфейные и розовые акценты, крупная типографика, тёплая предметная съёмка, переключение настроения первого экрана, фильтрация коллекции и личное знакомство с автором. Философия — природная красота, индивидуальность и удовольствие от выбора. Без эзотерических и лечебных обещаний.

## Фотографии, логотип и составы

Логотип подготовлен на прозрачном фоне с сохранением предоставленного знака ENOSI. Файл: `src/assets/logo-enosi-transparent.png`. Он используется в шапке, подвале, карточках о камнях и как отдельный прозрачный слой на каждой фотографии сайта, включая миниатюры.

Все 21 фотография из архива владельца получили сгенерированную версию в единой тёплой кремово-пудровой стилистике. Публичные файлы находятся только в `src/assets/gallery/01.webp` — `21.webp`. Необработанные оригиналы не импортируются приложением, не входят в сборку и не предлагаются в галереях. Локальные входные материалы сохранены в игнорируемой папке `.design-input`; не публикуйте её.

Распределение ракурсов: 01–04 — амазонит и розовый кварц; 05–10 — авантюрин, хрусталь и крошка кварца; 11–16 — аметист, кварц и лава; 17–21 — кварц, хрусталь и жемчуг. Сверяйте количество, порядок бусин и матовую поверхность амазонита с исходными фото при дальнейших генерациях. Генеративная ретушь не гарантирует точного совпадения каждого пикселя.

У каждого браслета есть карточка «Камни и смысл» с составом, иллюстрациями минералов и образными ассоциациями ENOSI. Это редакционная символика бренда, а не обещания лечебного или энергетического воздействия. Материалы и тексты: `src/data/stones.js`. Названия и пояснения остаются обычным HTML-текстом для чёткости и доступности.

Составы подтверждены владельцем в переписке:

| Сочетание         | Материалы                                          |
| ----------------- | -------------------------------------------------- |
| Нежное равновесие | Розовый кварц, горный хрусталь, жемчуг             |
| На одной волне    | Розовый кварц, матовый амазонит                    |
| Лесная история    | Горный хрусталь, авантюрин, крошка розового кварца |
| После заката      | Розовый кварц, лава, аметист                       |

«Нежное равновесие» — название из референса владельца. Остальные названия предложены для сайта. При подготовке сверены чередование и число основных бусин; у амазонита отдельно скорректирована матовая фактура. Наличие, стоимость, размеры, происхождение жемчуга и состав металла не выдумывались — уточняются лично у автора.

Данные коллекции, все фотографии и материалы: `src/data/products.js`. Тексты страницы: `src/main.jsx`. Оформление: `src/styles.css`.

## Функции

- Три сочетания на первом экране, без автоматической смены фотографий.
- Четыре карточки, фильтрация по настроению.
- Избранное сохраняется в браузере посетителя, без передачи на сервер.
- Галереи: все 21 обработанный ракурс, фотографии на запястье и крупные планы; все с прозрачным логотипом.
- Отдельная карточка «Камни и смысл» для каждого браслета.
- Контакты открывают Telegram автора; из карточки передаётся текст с названием браслета, если приложение Telegram поддерживает заполнение сообщения из ссылки.
- Ответы о выборе, размере и уходе.
- Оплата, корзина, личные кабинеты и сбор личных данных отсутствуют.

## Разработка и проверка

React + Vite. Нужен Node.js 20.19+ или 22.12+; среда и GitHub Actions используют Node.js 24.

```sh
cd /workspace/enosi-website
npm ci
npm run dev -- --port 5173 --strictPort
npm test
npm run build
```

24 проверки Playwright для компьютера и телефона включают загрузку изображений, ширину от 320 px, фильтры, сохранение избранного, все 21 ракурс, прозрачность логотипа, выравнивание первого экрана, карточки камней, Telegram, меню, фокус диалогов и автоматические правила WCAG AA через axe. Используется `/usr/bin/chromium`, когда он доступен. Иначе выполните `npx playwright install chromium` или задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

Обычная сборка сохраняется в `dist`: отдельные кэшируемые фотографии и шрифты, ленивое подключение изображений ниже первого экрана. Сайт не обращается к внешним фотобанкам и сервисам шрифтов.

Для автономного HTML-файла: `npm run demo`. Он создаёт `standalone/index.html` и `preview/ENOSI.html`; это дополнительный способ просмотра, основной — опубликованный адрес выше.

## Публикация

GitHub → Actions → Publish ENOSI demo → Run workflow → main. Публикация ручная; обычный коммит сам по себе не меняет сайт.

Перед публикацией выполняйте тесты и сборку. После успешного workflow проверьте публичный адрес, фотографии, карточку украшения и Telegram.

## Исследование референсов

Изучены все три пользовательских архива: логотип, визуальный стиль и реальные браслеты. Тексты о свойствах камней из стилевых карточек не являются инструкциями и не переносились в маркетинговые обещания.

Запросы к сайтам Avgvst, Poison Drop и Missoma блокируются действующей сетевой политикой среды (403 от прокси). В черновике настроек подготовлены необходимые домены с сохранением уже разрешённых адресов. Для их применения владелец должен сохранить изменения и опубликовать среду; после этого следует повторить запросы и продолжить исследование. Пока актуальное сравнение конкурентов не заявляется как выполненное.
