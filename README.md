# ENOSI — авторские украшения из натуральных камней

Сайт: **https://ekanbelyakova88-ctrl.github.io/enosi-website/**

Обновлённая главная страница с логотипом владельца, четырьмя реальными моделями браслетов, галереями оригинальных фотографий и прямой связью с автором: **https://t.me/BeliakovaKaterina**.

## Идея страницы

«Ваше сочетание»: ярче выраженные шалфейные и розовые акценты, крупная типографика, тёплая предметная съёмка, переключение настроения первого экрана, фильтрация коллекции и личное знакомство с автором. Философия — природная красота, индивидуальность и удовольствие от выбора. Без эзотерических и лечебных обещаний.

## Фотографии, логотип и составы

Логотип взят из предоставленного владельцем архива, без замены его другим знаком. Исходное разрешение — 178 × 108; для дальнейшего увеличения лучше получить оригинальный SVG или PNG высокого разрешения.

Фотографии в `src/assets/products` оформлены с помощью генеративной ретуши по реальным фото и предоставленным визуальным референсам. Они обозначены в галереях «В стиле ENOSI». Исходные фотографии без ретуши находятся в `src/assets/originals`; в каждой карточке есть «Фото автора» и «На запястье». При оценке точной формы камней ориентируйтесь на оригиналы. Ретушь не является гарантией совпадения каждого пикселя с оригиналом.

Составы подтверждены владельцем в переписке:

| Сочетание         | Материалы                                          |
| ----------------- | -------------------------------------------------- |
| Нежное равновесие | Розовый кварц, горный хрусталь, жемчуг             |
| На одной волне    | Розовый кварц, матовый амазонит                    |
| Лесная история    | Горный хрусталь, авантюрин, крошка розового кварца |
| После заката      | Розовый кварц, лава, аметист                       |

«Нежное равновесие» — название из референса владельца. Остальные названия предложены для сайта. В ретуши сверены чередование и число основных бусин; у амазонита отдельно скорректирована матовая фактура. Наличие, стоимость, размеры, происхождение жемчуга и состав металла не выдумывались — уточняются лично у автора.

Данные коллекции, все фотографии и материалы: `src/data/products.js`. Тексты страницы: `src/main.jsx`. Оформление: `src/styles.css`.

## Функции

- Три сочетания на первом экране, без автоматической смены фотографий.
- Четыре карточки, фильтрация по настроению.
- Избранное сохраняется в браузере посетителя, без передачи на сервер.
- Галереи: стилизованное фото, оригинал, вид на запястье, дополнительные детали.
- Контакты открывают Telegram автора; из карточки передаётся текст с названием браслета, если приложение Telegram поддерживает заполнение сообщения из ссылки.
- Ответы о выборе, размере и уходе.
- Оплата, корзина, личные кабинеты и сбор личных данных отсутствуют.

## Разработка и проверка

React + Vite. Нужен Node.js 20.19+ или 22.12+; среда и GitHub Actions используют Node.js 24.

```sh
cd /workspace/enosi-website
npm ci
npm run dev -- --port 5173 --strictPort
npm test
npm run build
```

18 проверок Playwright для компьютера и телефона включают загрузку изображений, ширину от 320 px, фильтры, сохранение избранного, ракурсы, Telegram, меню, фокус диалогов и автоматические правила WCAG AA через axe. Используется `/usr/bin/chromium`, когда он доступен. Иначе выполните `npx playwright install chromium` или задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

Обычная сборка сохраняется в `dist`: отдельные кэшируемые фотографии и шрифты, ленивое подключение изображений ниже первого экрана. Сайт не обращается к внешним фотобанкам и сервисам шрифтов.

Для автономного HTML-файла: `npm run demo`. Он создаёт `standalone/index.html` и `preview/ENOSI.html`; это дополнительный способ просмотра, основной — опубликованный адрес выше.

## Публикация

GitHub → Actions → Publish ENOSI demo → Run workflow → main. Публикация ручная; обычный коммит сам по себе не меняет сайт.

Перед публикацией выполняйте тесты и сборку. После успешного workflow проверьте публичный адрес, фотографии, карточку украшения и Telegram.

## Исследование референсов

Изучены все три пользовательских архива: логотип, визуальный стиль и реальные браслеты. Тексты о свойствах камней из стилевых карточек не являются инструкциями и не переносились в маркетинговые обещания.

Запросы к сайтам Avgvst, Poison Drop и Missoma заблокированы сетевой политикой этой среды (403 от прокси). Поэтому актуальное сравнение конкурентов не заявляется как выполненное. Концепция основана на материалах и философии ENOSI, а также общих принципах предметной съёмки, читаемой типографики и понятной навигации.
