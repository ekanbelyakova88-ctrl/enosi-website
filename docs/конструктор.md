# Конструктор: материалы и ограничения

Конструктор сохраняет данные только в браузере. Фактическая стоимость и посадка не рассчитываются: автор согласует их с покупательницей. Дополнительные подвески можно описать в пожеланиях. В первой версии повторяется вся последовательность, симметричного режима нет. Изображения являются условными SVG-иллюстрациями.

## Каталог материалов

Файл `src/data/materials.js` содержит 30 строк в порядке списка владелицы. Постоянные идентификаторы `m01`…`m30` используются в сохранённых эскизах: при изменении каталога нельзя переставлять строки или переиспользовать ID. Поля включают полное исходное описание, материал, форму, размеры, условный размер для изображения, цвет, путь к изображению, наличие, неизвестный остаток (`null`), неизвестную цену (`null`), активность и пометку согласования.

Для нового материала добавьте строку с новым постоянным ID, например `['m31', 'Название', 'Исходное описание', 'круглая', '8 мм', 8, '#b5c9bb'],` в список `rows` и соответствующий файл `src/assets/materials/m31.svg`. Не меняйте ID текущих записей. Чтобы заменить рисунок, замените соответствующий файл `src/assets/materials/m01.svg` и проверьте совместимость в браузере. В `materialSettings` добавьте, например, `m01: { available: false }`, чтобы отметить горный хрусталь как отсутствующий; `m01: { available: true }` возвращает его. В будущем можно указать `price: 120` и `stock: 12`, но пока расчёт цены конструктора не включён. `active: false` скрывает позицию из списка, сохраняя старые эскизы. Вставлять пароли в клиентский код нельзя.

Изображение для скачивания и текст берут элементы из одной последовательности. Текст можно выделить и скопировать вручную, если буфер обмена недоступен. Кнопки Telegram и MAX лишь открывают контакт, они не отправляют сообщение и не прикладывают рисунок.
